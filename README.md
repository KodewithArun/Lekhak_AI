## Lekhak AI

Lekhak AI is an AI-powered content creation platform designed to streamline and automate the process of generating high-quality written material. Leveraging Google's Agent Development Kit (ADK) for advanced agent orchestration and Streamlit for an intuitive web interface, Lekhak AI enables users to plan, route, and produce content efficiently. The platform integrates with PostgreSQL for robust data management and uses modular agents to handle tasks such as request analysis, content generation, and formatting. Whether you're creating blog posts, social media updates, or other written content, Lekhak AI provides a scalable and extensible solution for modern content workflows.

## Project Status

### Completed Features

- Content Generation Agents: Modular agents for maintaining the Sequential Flow of content creation

- Planner Agent: Fully functional request analysis and routing logic
- Pipeline Router Agents: Specialized agents for social media and blog content generation
- Streamlit Web Interface: Complete user interface for content generation workflows
- PostgreSQL Integration: Database persistence for sessions and user data

### In Development

- Content Generation Pipelines: Refinement and enhancement of social media and blog content pipelines with error handling, and output quality

### Note on Pipelines Progress

The current pipelines are implemented for testing purposes and serve as proof-of-concept implementations. They will be refined and enhanced in future iterations to include more sophisticated content generation algorithms, better error handling, and improved output quality.
